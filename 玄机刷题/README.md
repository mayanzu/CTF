本目录归档玄机平台刷题指南、逐题记录、原始附件和用于复核的分析资料。项目根目录原有的 CTF 课程讲义工程保持原位。

## 目录结构

- `指南/`：状态总览、合并 Markdown 源稿和可编辑 LaTeX 样式文件；旧版构建中间文件位于 `指南/历史构建/`。
- `记录/`：逐题解题记录、补充记录和整理归档操作记录。
- `题目资料/<题目>/附件/`：题目原始附件；Pixel Cage 的两个原始 ZIP 和 `challenge.png` 已从 Downloads 复制到本目录，原下载文件未移动。
- `题目资料/<题目>/`：每道题单独归档附件、分析源码和结果。按用途拆分的题目使用 `附件/`、`分析脚本/` 等子目录；早期材料仍在题目目录根层。
- `题目资料/<题目>/分析产物/`、`过程证据/`：保留的关键逆向结果和图像证据。
- 题目补充调试文件放在对应题目的 `工作区/`；`go_for_it_556/probes/` 保存探测输入和输出。
- `指南/历史构建/`：旧版 LaTeX 编译中间文件，与最终讲义分开保存。
