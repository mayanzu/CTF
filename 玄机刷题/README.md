# 玄机平台刷题资料

从 [玄机刷题指南.pdf](指南/玄机刷题指南.pdf) 开始阅读。指南按题型编排，逐题说明题目、用到的知识、操作步骤与结果。可编辑源稿和构建说明在 [指南/README.md](指南/README.md)。

## 查找一道题

1. 在 [题目资料分类索引](题目资料/题目分类/README.md) 中选择题型和题目。
2. 进入题目目录，先读 `wp.md` 或 `WP.md`，再看 `originals/`、`附件/` 等原始材料和 `analysis/` 中的复现脚本。各题保留原有命名，以免破坏题解里的命令。
3. 需要逐行核对终端输入和输出时，进入 [记录/题目记录](记录/README.md) 查看对应题目的 `完整过程记录.md`。跨题批次和项目整理记录也集中在该目录。

## 目录说明

| 位置 | 内容 |
| --- | --- |
| `指南/` | 发布版 PDF、Markdown 与 LaTeX 源稿、构建脚本 |
| `题目资料/题目分类/` | 按题型整理的题目附件、独立 WP 与复现材料 |
| `题目资料/原始下载附件/` | 原始题包及 SHA256 来源索引 |
| `记录/` | 按题目、批次、项目分组的完整命令与输出记录 |

`题目资料/` 顶层的同名目录是旧路径兼容入口，指向 `题目分类/` 下的原件；它们不占用第二份附件空间。修改资料时以分类目录为准。`figures/`、`labs/`、`tools/` 也是指向上一级 CTF 目录共享资源的入口。移动资料时请保留整个 CTF 文件夹。

## 更新指南

在 CTF 根目录运行：

```powershell
& .\玄机刷题\指南\build.ps1
```

该命令读取 `指南/玄机刷题指南_合并源.md` 并生成 PDF，需要 `pandoc` 与 `xelatex`。
