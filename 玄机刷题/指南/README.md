# 玄机刷题指南

- `玄机刷题指南.pdf`：学生阅读版。
- `玄机刷题指南_合并源.md`：可编辑的正文源稿。
- `玄机刷题指南.tex`、`玄机刷题指南_样式.tex`：LaTeX 排版文件。
- `build.ps1`：从 Markdown 生成正文并编译 PDF，需要 `pandoc` 和 `xelatex`。

修改源稿后，从 CTF 根目录运行：

```powershell
& .\玄机刷题\指南\build.ps1
```

构建时生成的 `玄机刷题指南_正文.tex` 留在本目录，LaTeX 辅助文件写入 `../../tmp/guide-build/`。

逐题附件和复现材料见 `../题目资料/题目分类/`；完整的命令与输出记录见 `../记录/`。
