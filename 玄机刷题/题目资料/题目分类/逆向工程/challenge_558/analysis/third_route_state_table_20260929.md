## 1. 从 main 还原有效 key

### 1.1 原始 key

main 在 0x1400041b8 分配 8 字节，然后从 0x1400041d1 开始写入：

| 索引 | 写入字节 | ASCII |
|---:|---:|:---:|
| 0 | 6c | l |
| 1 | 6e | n |
| 2 | 74 | t |
| 3 | 66 | f |
| 4 | 76 | v |
| 5 | 70 | p |
| 6 | 75 | u |
| 7 | 73 | s |

所以刚写入后的字节串是 lntfvpus。随后 main 构造索引 0 到 7 的迭代范围；在 0x14000429b 对 key[i] 取可变引用。循环尾部的指令是：

    0x1400043ff  mov rax, [rbp-0x38]   ; key[i] 的可变引用
    0x140004403  mov cl,  [rbp-0x39]   ; 当前索引 i
    0x140004406  xor cl,  [rax]       ; key[i] XOR i
    0x140004408  mov [rax], cl        ; 写回 key[i]

循环回到 0x140004243，直到 8 个字节都处理完。按此代码逐项计算：

| i | 原始字节 | XOR i | 有效字节 | 字符 |
|---:|---:|---:|---:|:---:|
| 0 | 6c | 00 | 6c | l |
| 1 | 6e | 01 | 6f | o |
| 2 | 74 | 02 | 76 | v |
| 3 | 66 | 03 | 65 | e |
| 4 | 76 | 04 | 72 | r |
| 5 | 70 | 05 | 75 | u |
| 6 | 75 | 06 | 73 | s |
| 7 | 73 | 07 | 74 | t |

有效 key 是 loverust。遗漏这段 main 逻辑会让后续算法本身看起来自洽，但解出的明文不可读。

## 2. KSA 状态表构造

main 在 0x1400042d5 调用 0x140003c80，并传入 key、key 长度和输出状态对象。

### 2.1 初始状态

0x140003c80 先调用 0x140005120 构造从 0 到 255 的 inclusive range；收集器的 size hint 通过 end-start+1 得到 256，最终状态向量长度为 256。因此：

    S = [0, 1, 2, ..., 255]

KSA 的 i 遍历 0 到 255，共 256 轮；局部 j 初始为 0。后续闭包构造还会把这同一状态向量捕获到变换环境中。

### 2.2 KSA 循环证据与公式

在 0x140003e19–0x140003e34，指令用 i 除 key 长度取余、读 key[i % 8]，再 XOR 0x66。0x140003e41–0x140003e4c 按 i 读取 S[i]。随后 0x140003e67–0x140003e8d 把旧 j、S[i] 和 keybyte 相加；0x140003ea8–0x140003eaf 只保留结果低 8 位，写回 j。0x140003ed7–0x140003ef8 将 i、j 及状态切片交给交换 helper。

对应的 KSA 为：

    S = [0, 1, ..., 255]
    j = 0
    for i in range(256):
        kb = key[i % 8] XOR 0x66
        j = (j + S[i] + kb) mod 256
        swap(S[i], S[j])

key 在这里是 main 已处理过的 loverust。自编译校验器得到的状态表前 16 字节为 0a148c2c1e9a43b96f3839683f123656；状态表长度为 256。

## 3. PRGA 变换闭包

### 3.1 初始计数器与状态表来源

在 KSA 所在函数构造变换闭包时，0x140003d80 将局部 i 初始化为 0，0x140003d86 将局部 j 初始化为 0。0x140003dbb–0x140003dca 将这两个局部变量的地址放入环境，0x140003dd1–0x140003dd5 将同一个函数栈上的 S 向量地址放入第三个环境字段。随后在 0x140003dea 调用闭包构造 helper。

闭包 0x140003f40 从环境偏移 0、8、0x10 读取 i 指针、j 指针和 S 向量。因此 PRGA 从 i=j=0 开始，且沿用 KSA 修改后的 S。

### 3.2 每个字节的状态更新与变换

0x140003f4f–0x140003f77 将 i 加 1 并按 0xff 掩码；0x140003f7a–0x140003fdd 读取 S[i]、更新 j，并按 0xff 掩码。0x140003fe0–0x140004013 交换 S[i] 与 S[j]。0x140004021–0x1400040a9 读取 S[i]、S[j]，计算并访问索引 (S[i]+S[j]) mod 256。最后 0x1400040ac–0x1400040c1 先交换半字节、加一，再与输入 XOR 并加一。

逐字节公式：

    i = (i + 1) mod 256
    j = (j + S[i]) mod 256
    swap(S[i], S[j])
    K = S[(S[i] + S[j]) mod 256]
    nibble_swap(K) = ((K << 4) | (K >> 4)) mod 256
    mask = (nibble_swap(K) + 1) mod 256
    C = ((P XOR mask) + 1) mod 256

注意加一的位置：mask 内的加一先于 XOR；最终输出还会再加一。解密时先减去外层的一，再执行 XOR：

    P = ((C - 1) mod 256) XOR mask
