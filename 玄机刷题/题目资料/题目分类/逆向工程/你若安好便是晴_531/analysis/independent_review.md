# #531「你若安好便是晴」独立复核

## 复核范围

复核只读取 `are_you_ok.zip`、`你好吗.exe`，以及已保存的 `decrypt_static.py`、反汇编和符号摘录。另用一段独立编写的 Python 标准库代码从硬编码的反汇编常量复算，不调用 `decrypt_static.py`，不运行或加载 EXE，也不联网或操作平台。命令和完整输出见本目录的 `independent_review_commands.log`、`independent_review_output.txt`。

## 核对结果

| 检查项 | 结果 |
|---|---|
| ZIP 内 EXE 与 `extracted/你好吗.exe` | 逐字节相同；大小均为 132,122 bytes |
| 内嵌十六进制文本 | 64 个字符，即 32 字节 |
| TEA 分组 | 32 字节按 8 字节分组，共 4 块 |
| TEA 参数 | 32 轮；delta `0x9e3779b9`；key `12345678, 87654321, abcdef98, 98fedcba` |
| TEA 反向验证 | 用相同参数重新加密解密出的 4 块，逐字节还原内嵌密文 |
| 解密缓冲区 | 32 bytes，无内嵌 NUL；末尾六字节为 `06 06 06 06 06 06`，其前字节为 `0x6b` |
| `sub_102` 截断 | `strlen = 32`，末字节作为 signed char 为 `+6`，故在偏移 `32 - 6 = 26` 写 NUL |
| 最终字符串 | 26 个 ASCII 字节；不含 NUL 或换行 |

## 字节级复算

独立复算的 TEA 解密结果为：

```text
707a77716d2f732120732321743b772f24273b227574753b2e6b060606060606
```

前 26 字节在 `sub_102` 写入 NUL 后被 `sub_100` XOR `0x16`，后六个 `0x06` 不属于 C 字符串。最终字节及其长度为：

```text
ASCII: flag{9e76e57b-a921-4cbc-8}
HEX:   666c61677b39653736653537622d613932312d346362632d387d
长度:  26 bytes
```

其中偏移 26 的 NUL 是字符串终止符，不包含在候选中；也没有其它有效字符位于它之前之后需要加入。结果尾部分组长度看起来不常见，但源码机器码路径明确只处理这 26 个字符串字节，复算没有依据补全或修整它。

## 对原静态脚本的审计

`decrypt_static.py` 对此样本的关键步骤与反汇编相符：从 `main` 的八条 `movabs` 立即数拼接 64 位十六进制文本；从局部 dword 赋值取出四个 TEA 密钥字；根据 `sub_101` 的初始 sum、delta 与 `cmp 0x1f` / `jbe` 回边得到 32 轮；依次做 v1、v0 的 TEA 反向更新；按 `sub_102` 的有符号末字节表达式截断；最后依照 `main` 传给 `sub_100` 的 `0x16` 异或。独立代码也从这些参数重新计算并通过密文回验。

填充处理在一般输入上较脆弱：`sub_102` 只看末字节，且 `movsx` 意味着高位为 1 的末字节会被解释为负值；它没有验证整个填充区。本题实际末字节为 `0x06`，前六字节也全为 `0x06`，长度运算落在 `[0, 32]` 内，所以该边界问题不改变本题结果。

## 结论

独立复算支持将完整静态恢复候选写为 **`flag{9e76e57b-a921-4cbc-8}`**。末尾单字符 `8` 是计算结果的一部分；偏移 26 的终止 NUL、缓冲区中剩余的六个填充字节和换行都不属于候选。是否满足题目平台的额外提交规则未验证，因为本复核没有提交候选。
