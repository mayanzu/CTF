# 离线练习与平台复现

从 CTF 根目录运行命令，题目数据和脚本中的相对路径以该目录为基准。

| 目录 | 内容 |
| --- | --- |
| `web/` | 本地 Web 入门靶场 `app.py` |
| `crypto/` | XOR、RSA 练习数据及生成脚本 |
| `reverse/` | C 程序与校验脚本 |
| `pwn/` | 本地溢出、格式串练习源码和辅助脚本 |
| `misc/` | PNG、PCAP 练习数据及生成脚本 |
| `platform/` | 玄机平台附件和本地复现脚本 |

例如，在 CTF 根目录运行 `python .\labs\web\app.py` 启动本地 Web 靶场；按 `Ctrl+C` 停止。`platform/` 中的在线题脚本需要题目当前实例信息，离线练习以各讲义和逐题 WP 的步骤为准。
